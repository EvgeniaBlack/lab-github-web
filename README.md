# Информационная система управления каталогом музыкальных треков «SoundVault»
![Uploading 1791531453.png…]()

## Цель проекта
Разработка удобного веб-приложения для систематизации, поиска, хранения и воспроизведения музыкальных композиций с возможностью формирования персональных плейлистов и администрирования медиатеки.

## Список реализуемых навыков и возможностей
* Проектирование реляционной базы данных для музыкальных треков, альбомов и пользователей
* Разработка REST API на базе FastAPI и SQLAlchemy
* Создание адаптивного пользовательского интерфейса (UI/UX)
* Интеграция встроенного аудиоплеера с поддержкой базовых элементов управления
* Реализация многокритериального поиска и фильтрации треков по жанрам и исполнителям
